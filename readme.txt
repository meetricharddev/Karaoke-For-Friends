================================================================
 卡拉OK點歌機（上架準備版）— 安裝與使用說明
================================================================

【這是什麼】
一個放在網站上的卡拉OK點歌程式：用 YouTube 搜尋「伴奏MV（無人聲＋字幕）」，
排隊後自動在電腦瀏覽器播放。手機可以掃 QR code 幫忙點歌。
電腦和手機都可以「安裝成 App」，也可以再打包上架 Google Play / App Store。

資料夾內容
  site\        要上傳到網站的檔案（網頁程式）
  worker\      YouTube 代理伺服器（讓使用者不用自己申請金鑰；公開版才需要）
  singers.txt  各地區歌手名單（程式內建，方便你檢查或補充）
  readme.txt   本說明

----------------------------------------------------------------
【先選一種用法】
----------------------------------------------------------------
A. 自己或朋友使用（最簡單，約 10 分鐘）
   每個使用者在程式裡貼自己的 YouTube API 金鑰。只需要 site\ 資料夾。
   不需要 Worker。不適合公開上架。

B. 公開版（要給很多人用、或要上架商店）
   金鑰放在你的代理伺服器（Worker），使用者完全不用設定。
   需要 site\ + worker\，大約 30 分鐘。

----------------------------------------------------------------
【用法 A：自己或朋友使用】
----------------------------------------------------------------
1. 取得 YouTube API 金鑰（免費，約 5 分鐘；全部用下面的連結，不用自己搜尋）
   ① 用 Google 帳號登入後，開啟「建立專案」頁面：
        https://console.cloud.google.com/projectcreate
      專案名稱隨便填（例如 karaoke），按「建立」。（已經有專案可以跳過這步）
   ② 開啟「YouTube Data API v3」頁面，確認左上角是剛建立的專案，按藍色「啟用」：
        https://console.cloud.google.com/apis/library/youtube.googleapis.com
   ③ 開啟「憑證」頁面，按「＋建立憑證」→「API 金鑰」，會跳出一串 AIza 開頭的金鑰，按複製：
        https://console.cloud.google.com/apis/credentials
      （若出現問資料類型的選項，選「公開資料 Public data」。）
   ④ 建議再做一步，避免金鑰被別人拿去亂用：在憑證頁面點進剛建立的金鑰，
      「API 限制」選「限制金鑰」→ 只勾「YouTube Data API v3」→「儲存」。
   ⑤ 網頁程式的設定畫面裡也有同樣的步驟和連結，可以一邊看一邊做。
   查看用量（免費每天 10,000 單位）：
        https://console.cloud.google.com/apis/api/youtube.googleapis.com/quotas
2. 把 site\ 裡的所有檔案放到網站空間（任選一個，皆免費）：
   - Cloudflare Pages：dash.cloudflare.com →「Workers 和 Pages」→「建立」→
     「Pages」→「上傳資產」→ 把 site 資料夾裡的檔案全部拖進去 →「部署」。
   - 或 GitHub Pages（建立公開的 repository，上傳檔案，Settings → Pages 開啟）。
   完成後會得到網址，例如 https://karaoke.pages.dev
   （不要直接雙擊 index.html 開檔，YouTube 會拒絕播放，手機點歌也不能用。）
3. 用電腦的 Chrome 或 Edge 開啟網址，按右上角「⚙ 設定 YouTube API 金鑰」，
   貼上金鑰，按儲存。只需要做一次。
4. 按右上角「⬇ 安裝成 App」（或網址列右邊的安裝圖示），桌面就會有圖示。

----------------------------------------------------------------
【用法 B：公開版（Worker + 網站）】
----------------------------------------------------------------
步驟 1：取得 YouTube API 金鑰
  照「用法 A」第 1 點的連結操作即可（建立專案 → 啟用 → 建立 API 金鑰）。
  注意：第 ④ 步只做「API 限制」；「應用程式限制」請維持「無」
  （不要設網址限制，因為呼叫 YouTube 的是 Worker，不是瀏覽器）。

步驟 2：建立 Worker（YouTube 代理伺服器）
  1) 登入 dash.cloudflare.com →「Workers 和 Pages」→「建立」→「建立 Worker」。
  2) 名稱填 karaoke-proxy →「部署」→「編輯程式碼」，
     把 worker\worker.js 的內容全部貼上，覆蓋原本內容 →「部署」。
  3) 建立 KV（用來快取與記錄用量）：
     左側「儲存和資料庫」→「KV」→「建立命名空間」，名稱 karaoke-kv。
     回到 Worker →「設定」→「繫結」→「新增」→ KV 命名空間，
     變數名稱必須填 KV，選剛建立的命名空間。
  4) Worker →「設定」→「變數和機密」，新增：
     - YOUTUBE_API_KEY　　類型選「機密」，值＝你的金鑰
     - ADMIN_TOKEN　　　　類型選「機密」，值＝你自己訂的管理密碼（越長越好，只有你知道；產生升級碼用）
     - ALLOWED_ORIGINS　　值＝你的網站網址，例如 https://karaoke.pages.dev
                          （多個用逗號分隔；上架 Android 版再加 https://localhost）
     - DAILY_BUDGET　　　（選填）每天最多使用的額度，預設 9000
  5) 記下 Worker 網址，例如 https://karaoke-proxy.你的帳號.workers.dev
     用瀏覽器開 該網址/health，看到 {"ok":true} 就成功。

步驟 3：部署網站
  1) 用記事本打開 site\config.js，把 apiBase 改成 Worker 網址：
        apiBase: 'https://karaoke-proxy.你的帳號.workers.dev',
  2) 把 site\ 裡的所有檔案上傳到 Cloudflare Pages（同用法 A 第 2 點）。
  3) 回到 Worker 把 ALLOWED_ORIGINS 改成 Pages 網址。
  4) 用 Chrome 開啟網站，直接就能搜尋，不用設定金鑰。
  （apiBase 有填時，程式會自動隱藏「設定金鑰」按鈕。）

步驟 4：填寫法律頁面
  用記事本打開 site\privacy.html 和 site\terms.html，
  把 [請填入你的名稱]、[請填入你的信箱] 換成真實資料後重新上傳。

額度說明（重要）
  YouTube 免費額度每天 10,000 單位。每次「未命中快取」的搜尋約 101 單位，
  熱門榜約 1 單位。Worker 會快取 24 小時、每 IP 每分鐘限流、每天用到上限就停止，
  所以約等於每天可以有 90 次左右的新搜尋。人多時請向 Google 申請提高額度
  （YouTube API Services 的「Audit and Quota Extension」表單，審核需要數週）。
  額度用完時，使用者仍可用「貼上連結點歌」。

【使用方法】
----------------------------------------------------------------
電腦端（在電腦開啟網站或 App，播放都在這裡）
  🎼 探索
    - 先選地區：香港、中國大陸、台灣、日本、韓國、美國、歐洲。
    - 再選分類（依序）：
      👨 男歌手／👩 女歌手／👥 團體　點歌手名字，列出他的伴奏版。名單前面標有 🌱 的是
                                    出道 10 年內（約 2016 年後）的新生代，其後是經典與資深歌手
      👑 KTV經典　內建的各地區經典歌曲（每區約 36～44 首）
    - 經典歌曲列出的是原版，按「點歌」會自動找伴奏版並加入佇列；
      想自己挑版本就按「選版本」。
    - 日本地區（男歌手／女歌手／團體／KTV經典）有特別設定：
      · 搜尋會優先顯示「ひらがな／ローマ字（羅馬拼音）歌詞」的版本，順序是
        🎤 伴奏＋ひらがな/ローマ字 → 🔤 ひらがな/ローマ字歌詞 → 🎤 伴奏MV → 📝 歌詞版 → 其他。
      · 觀看門檻放寬為 4,000 次以上（其他地區仍是 10 萬次）。可在 config.js 的 minViewsJp 調整。
      · 只有「從日本探索點進去」的搜尋會這樣；自己輸入文字搜尋，仍用一般規則。
  🔍 搜尋　輸入歌名或歌手。結果依「🎤 伴奏MV（無人聲＋字幕）→ 📝 歌詞版 → 其他」分組，
           只列 10 萬次觀看以上的影片。每筆會顯示觀看次數與上傳日期。
  排序　「同類排序」可選「最多觀看」或「最新上傳」，在每一組內生效（探索與搜尋都有）。
  ★ 最愛、🕘 紀錄　每首歌旁的 ☆ 加入最愛。
  點歌人與公平輪流　填名字後點歌；勾選「公平輪流」時，每人輪流唱，不會被一個人連點霸佔。
  「插播」排到最前面；佇列可「置頂」「刪除」，也可「依輪流重新排序」。
  播放速度　「－ 慢／快 ＋」0.25x～2x，「重設」回 1x；可勾選「下一首保持此速度」。
  歌曲之間倒數　點歌設定裡可選不倒數、3、5、10 秒；倒數畫面在播放器下方。
  ⛶ 全螢幕演唱　影片在上、資訊列在下（下一首、倒數、切歌、重唱、變速、離開），
               按 Esc 也可離開。
  貼上 YouTube 連結點歌　找不到想要的版本時使用，不耗搜尋額度。

快捷鍵（先點一下頁面空白處；游標在輸入框、下拉選單或 YouTube 影片上時無效）
    N 或 →　　切歌（跳到下一首）
    R　　　　　重唱
    空白鍵　　暫停／播放
    F　　　　　全螢幕演唱
    [　　　　　變慢　　　]　　變快
  全螢幕時如果按鍵沒反應，是因為游標停在 YouTube 影片裡：先點一下下方的資訊列再按。

手機端（掃碼點歌）
  1. 電腦頁面右側「📱 手機掃碼點歌」會顯示 QR code（網站必須是 https 網址）。
  2. 手機用相機掃描，輸入名字，就能探索、搜尋、貼連結點歌；歌會排進電腦的佇列。
  3. 手機和電腦最好在同一個 Wi-Fi。電腦頁面要保持開著。
  4. 搜尋由電腦代為執行，手機端每次啟動最多 30 次搜尋，保護額度。

【方案與升級碼】
----------------------------------------------------------------
方案
- 免費版（尚未升級）：每次開啟程式，會先出現 10 秒的「等待畫面」（倒數完自動進入），
  畫面上有「升級，跳過等待」按鈕。等待期間不會開始播放任何影片。
  秒數可在 config.js 的 gateSeconds 調整。
- 升級版：一次付費，永久不再出現等待畫面。
- 沒有任何廣告。
- 等待畫面只在電腦的主程式出現；手機點歌頁沒有。

定價建議
- 建議 US$2.99 一次付費。北美一杯咖啡約 US$3.5～5，所以 US$1.99 或 US$2.99 都比一杯咖啡便宜。
- 顯示文字在 config.js 的 priceText；實際收費金額以你建立的付款連結為準，兩邊請保持一致。

收款（網頁版）與發放升級碼的流程
1. 用 Stripe Payment Links、Lemon Squeezy、Gumroad 或 Ko-fi 等，建立一個「US$2.99 一次付費」的商品，
   把付款連結貼到 config.js 的 checkoutUrl（升級視窗就會出現「購買升級碼」按鈕）。
   小額收款的固定手續費占比高（例如 Stripe 約 2.9% + 30 美分，實際以官方為準）；
   Lemon Squeezy、Paddle 這類代收代付平台會幫你處理各國銷售稅，但抽成較高。
2. 買家付款後，你會收到付款通知。
3. 用電腦雙擊開啟 admin\admin.html（只給你自己用，不要上傳到網站），
   填入 Worker 網址與管理密碼（ADMIN_TOKEN），按「產生 1 組」，
   再按「複製給買家的訊息」，用電子郵件寄給買家。
4. 買家在 24 小時內，到程式右上角「👑」（或等待畫面上的「升級，跳過等待」）輸入升級碼。
   成功後，那台裝置永久不再出現等待畫面。
   - 每組碼只能用一次；產生後超過 24 小時就失效（失效就再產生一組）。
   - 已升級的裝置再輸入新碼，不會消耗那組碼。
- 目前「收款 → 發碼」是手動的（你要在 24 小時內寄出）。想全自動，需要再串接付款平台的通知（webhook）。

裝置代碼與找回
- 「👑」視窗會顯示「裝置代碼」。升級狀態綁在這個代碼上（存在瀏覽器裡）。
- 買家換手機、或清除瀏覽器資料後，升級狀態會消失。請買家把新裝置的「裝置代碼」寄給你，
  你在 admin.html 的「找回／手動授權」貼上代碼，按「授權為升級版」，那台裝置重新開啟程式就會恢復。

已知限制
- 同一組碼被兩個人「同一瞬間」輸入，理論上可能兩人都成功（Cloudflare KV 不是即時一致）；機率很低。
- 上架商店的 App 若賣「解鎖」這類數位內容，必須使用 Google Play 帳務／Apple 內購（抽成約 15～30%），
  不能導向外部付款或使用外部升級碼（上架版請把 config.js 的 storeBuild 設為 true 以隱藏購買按鈕）。
  商店內購的串接本包沒有提供，需另外開發。

【上架 Google Play / App Store 概要】
----------------------------------------------------------------
先決條件：使用「用法 B」，網站有固定網址，並完成法律頁面。
1. 帳號費用：Google Play 開發者帳號約 US$25（一次）；Apple Developer Program 約 US$99／年。
2. Android：到 pwabuilder.com 輸入你的網站網址，選 Android 封裝，產生 .aab 上傳 Play Console。
   需要在網站放 /.well-known/assetlinks.json（PWABuilder 會告訴你內容）。
   在 Worker 的 ALLOWED_ORIGINS 加入打包版會用到的網址（依 PWABuilder 說明）。
3. iOS：需要 Mac 與 Xcode（或雲端 Mac 服務，如 Codemagic）。PWABuilder 也能產生 iOS 專案。
   Apple 審核常以「只是包裝網站」（指南 4.2）退件，不保證通過。
4. 先把 YouTube API 的合規做好：
   - 只能用官方嵌入式播放器；播放器不可被遮蓋、不可分離或修改音訊畫面（本版已把所有資訊移到播放器外）。
   - App 內要有 YouTube 服務條款與 Google 隱私權政策連結（頁尾已提供）。
   - 儲存的 YouTube 資料超過 30 天要更新或刪除（本版已處理：紀錄與佇列 30 天清除，最愛會自動更新）。
   - 公開版建議申請提高額度並通過 API 審核；付費功能請對照最新的 YouTube 開發者政策。
5. 商店資料：隱私權政策網址（你的網站/privacy.html）、App 圖示 512×512、
   截圖（手機與平板）、簡介文字、內容分級、資料安全問卷。
6. 著作權風險：影片由第三方上傳，可能含未授權的卡拉OK版本。本程式不代管影片，
   但審核與法律風險仍存在，建議上架前諮詢專業人士。
上述是我整理的流程重點，不是法律意見；請以 Google、Apple、YouTube 官方最新文件為準。

【已知限制】
----------------------------------------------------------------
- 沒有「音畫延遲」調整：YouTube 嵌入播放器無法單獨延遲聲音或畫面，
  而且 YouTube 政策禁止分離或修改影片的音訊／畫面，所以無法在程式內做。
  若聲音比畫面慢（常見於藍牙喇叭／耳機）：改用有線，或在電視／擴大機／藍牙裝置
  的設定裡調整「音畫同步（Lip sync）」。
- 歌手與經典歌曲是內建清單，不是即時榜單。韓國、日本、美國參考了公開榜單，
  香港、台灣、中國大陸、歐洲主要是我整理的，可能有疏漏（見 singers.txt，可直接改 index.html 內的 ART 與 CLASSIC）。
- 自動挑伴奏版是依標題關鍵字判斷，偶爾會挑錯，可按「選版本」自己選。
- 觀看次數低於門檻的影片一律不顯示（一般 10 萬次，可改 config.js 的 minViews；日本 4,000 次，可改 minViewsJp）。冷門歌曲可能找不到結果。
- 手機點歌使用 PeerJS 公共配對服務；部分公共 Wi-Fi 或公司網路會擋住點對點連線。
- 這份程式在開發環境用模擬資料測試過邏輯，但沒有在真實的 YouTube、Cloudflare、
  手機與商店環境完整測試過，上線前請自己完整試一遍。

----------------------------------------------------------------
【疑難排解】
----------------------------------------------------------------
- 搜尋顯示「今日的搜尋額度已用完」：額度每天（太平洋時間午夜）重置；先用貼連結點歌。
- 「請先設定 YouTube API 金鑰」：用法 A 要貼金鑰；用法 B 檢查 config.js 的 apiBase 是否正確。
- 搜尋失敗、瀏覽器主控台出現 CORS 錯誤：Worker 的 ALLOWED_ORIGINS 要等於網站網址（含 https://，結尾不要有 /）。
- 影片無法播放（錯誤 153）：不要直接開檔，要用網址開啟。
- 手機一直「連線中」：確認電腦頁面開著、網址是 https；換手機熱點或家用 Wi-Fi 試試。
- QR code 沒出現：網站要是 https 網址，不能是 localhost 或本機檔案。
- 升級碼無效：升級碼只能用一次，且產生後 24 小時內才有效；請重新在 admin.html 產生一組。
  也請確認 config.js 的 apiBase 正確，且 Worker 已綁定名稱為 KV 的 KV、並設定了 ADMIN_TOKEN。
- admin.html 顯示「管理密碼錯誤」：Cloudflare 設定的 ADMIN_TOKEN 與你輸入的不一樣（大小寫要相同）。
- 升級後還是出現等待畫面：重新整理頁面；若換過瀏覽器或清除過資料，請用「裝置代碼」找回（見上方說明）。
- 更新程式：把新檔案重新上傳覆蓋；使用者的最愛與設定不受影響。
